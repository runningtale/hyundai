# 개발 환경 설정

> 최종 수정 2026-11-12 / 공식 안내: https://document.pleos.ai/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator
> 처음 한 번만 하면 됩니다. 막히면 팀에 바로 공유해 주세요.

## 1. 준비물

| 항목 | 버전 |
|---|---|
| Android Studio | 최신 (https://developer.android.com/studio?hl=ko) |
| JDK | 17 이상 (Android Studio 내장 JDK 사용 가능) |
| Android SDK | API 34 플랫폼, build-tools 34 |
| Pleos Connect Emulator | 2.1.0 이상 (Virtual Console 사용에 필요) |
| PC | Android 에뮬레이터 요구 사항 충족 (https://developer.android.com/studio/run/emulator?hl=ko#requirements), RAM 4GB 이상 여유 |

- 이전 버전 Pleos 에뮬레이터가 있으면 먼저 지웁니다.

## 2. Pleos 시스템 이미지 설치 (SDK Manager)

1. Android Studio → **Tools → SDK Manager**
2. **SDK Update Sites** 탭 → 왼쪽 위 **+**
3. 입력
   - Name: `Pleos Connect System Image`
   - URL (Windows/Linux): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
   - URL (Mac): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-arm64-sys-img.xml`
4. **SDK Platforms** 탭 → 아래 **Show Package Details** 켜기 → **Android API 34**의 Pleos Connect system image 체크 → OK
5. 설치가 끝나면 Android Studio 재시작

설치되면 `Android/Sdk/system-images/android-34/pleos_car_emulator/x86_64`가 생깁니다 (제공: 42dot, 태그: android-automotive).

## 3. AVD(가상 차량) 만들기

1. **Tools → Device Manager → Create device**
2. Form Factor: **Automotive** → **Pleos Connect v2.1.0** → Next
3. **Advanced Settings**
   - Startup → Default boot: **Cold**
   - Emulated Performance → RAM: **4 GB**
4. Device 탭 → API **34** → **Pleos Connect v2.1.0 APIs** → Finish

참고로 팀 PC에서 쓰는 AVD 설정: 이름 `Pleos_Connect`, 2560×1440, 160dpi, CPU 4코어, RAM 4GB, 데이터 6GB.

## 4. 에뮬레이터 실행

- Android Studio Device Manager에서 실행, 또는 명령줄:
  ```bash
  # Windows (Git Bash)
  "$LOCALAPPDATA/Android/Sdk/emulator/emulator.exe" -avd Pleos_Connect
  ```
- 부팅 확인: `adb shell getprop sys.boot_completed` → `1`

## 5. 프로젝트 빌드와 설치

```bash
git clone https://github.com/runningtale/hyundai.git C:/dev/hyundai   # 영문 경로 권장
cd C:/dev/hyundai
git config user.name "RunningTale"                # CONTRIBUTING.md 1장
git config user.email "team@runningtale.invalid"
./gradlew :app:installDebug                        # 에뮬레이터가 켜져 있어야 함
```

- `local.properties`는 Android Studio가 만들어 줍니다. 명령줄만 쓰면 직접 만듭니다: `sdk.dir=C\:/Users/<사용자>/AppData/Local/Android/Sdk`
- LLM 키는 같은 파일에 `LLM_API_KEY=...` (없으면 데모 모드)
- 앱을 다시 설치하면 미디어 앱이 끊긴 연결을 붙잡고 있어 목록이 계속 로딩 중으로 보입니다. `adb shell am force-stop ai.umos.mediaapp` 후 다시 엽니다

## 6. 앱 실행 (재생 화면 없는 오디오 앱)

```bash
# 차 미디어 화면에 달리는 동화를 띄움
adb shell am start -a android.car.intent.action.MEDIA_TEMPLATE \
  --es android.car.intent.extra.MEDIA_COMPONENT com.runningtale/.playback.StoryMediaService
```

- 화면에 "이야기" 탭 → **출발하며 듣기**를 누르면 재생
- `adb shell input keyevent KEYCODE_MEDIA_PLAY`는 에뮬레이터에서 앱까지 전달되지 않음 (앱은 사용자 10에서 돌고 adb 키는 다른 사용자로 감). 화면을 누르거나 `adb shell input tap 1090 370`
- 시연용 이벤트 주입은 README "시연" 절

## 7. Virtual Console (차량 값 바꾸기)

```bash
adb forward tcp:8088 tcp:8088
# 브라우저에서 http://127.0.0.1:8088
```

- 위쪽 **Emulation Controls**에서 공조, 독서등, 좌석, 도어, 와이퍼, 전조등 값을 바꾸거나 확인
- **주행 상태 만들기**: 위쪽 기어를 **D**로 바꾸고 **ACCEL**을 누르고 있으면 속도가 올라가며 주행 규제가 켜짐. 놓고 **P**를 누르면 정차
- 공식 문서의 `adb shell cmd hmg_car_service ... driving_regulation on` 명령은 지금 이미지에는 서비스가 없어 동작하지 않음 (2026-11-12 확인)
