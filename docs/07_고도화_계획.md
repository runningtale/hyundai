## 1. 이야기 만들기 (가장 중요)

### 1-1. 좋은 차량 오디오 동화의 원칙

| 원칙 | 이유 | 구체적으로 |
|---|---|---|
| 귀로만 듣는다 | 화면을 못 봄 | "보세요"보다 "들려요, 느껴져요". 소리 흉내말(휘이잉, 찰방찰방) 문장마다 하나 이상 |
| 짧게 말한다 | 운전 소음, 아이 집중 시간 | 문장 40자 이내, 4~5세는 25자 이내 |
| 이름을 부른다 | 아이가 주인공이라는 느낌 | 장마다 주인공 이름 2~3번. 너무 자주 부르면 어색하니 3번 이하 |
| 되풀이한다 | 아이는 반복을 좋아하고 따라 말함 | 이야기마다 후렴 한 줄 ("통통 구름아, 어디로 갈까?"). 장마다 한 번 |
| 지금 길과 이어진다 | 이 앱만의 가치 | 장마다 실제 상황(비, 터널, 남은 시간) 한 번 이상 |
| 무섭지 않다 | 부모 신뢰 | 갈등은 "길이 막힘, 친구가 속상함" 수준. 악당 없음 |
| 끝이 목적지다 | 도착의 기대감 | 결말 장소 = 목적지를 이야기 속 장소로 바꾼 것 |

### 1-2. 연령대별 기준

| 항목 | 4~5세 | 6~7세 | 8~9세 |
|---|---|---|---|
| 문장 길이 | 25자 이내 | 35자 이내 | 40자 이내 |
| 장 길이 | 6~8문장 | 8~12문장 | 10~15문장 |
| 어휘 | 생활 단어, 의성어 많이 | 쉬운 상상 단어 | 새 단어 1~2개를 설명과 함께 |
| 줄거리 | 한 가지 목표 | 목표 + 작은 문제 하나 | 목표 + 문제 + 해결 아이디어 |
| 등장인물 | 2명 | 2~3명 | 3~4명 |
| 후렴 | 장마다 | 장마다 | 처음과 끝 |

### 1-3. 이야기 구조: 여정형 3막

| 막 | 차에서 일어나는 일 | 이야기에서 | 장 수 (2시간 기준) |
|---|---|---|---|
| 1막 출발 | 시동, 출발, 처음 30분 | 주인공 소개, 목표 제시("바다 왕국에 가야 해"), 길잡이 친구 등장 | 2장 |
| 2막 모험 | 고속도로, 터널, 휴게소, 날씨 변화 | 장소마다 작은 사건과 해결. 실제 도로 이벤트가 장면이 됨 | 5~7장 |
| 3막 도착 | 도착 15분 전부터 | 목적지가 보이기 시작, 모험 정리, 다음 여행 약속 | 2장 |

**장 하나의 구성**
1. 앞 장과 잇는 한 문장 ("동굴을 빠져나온 하윤은...")
2. 새 장소 소리로 묘사 (1~2문장)
3. 작은 사건 (2~4문장)
4. 차 연동 장면 (효과 태그가 붙는 문장, 장당 최대 2개)
5. 다음 장 떡밥 한 문장 ("저 멀리서 무언가 반짝였어요")

### 1-4. 세계관 팩 (P1)

LLM에게 아무 이야기나 만들게 하면 품질이 들쭉날쭉합니다. 미리 정한 **세계관 팩** 안에서 만들게 하면 일관성이 생기고, 나중에 캐릭터 IP 수익과도 연결됩니다.

| 팩 | 어울리는 목적지 | 길잡이 캐릭터 (목소리) | 대표 장소 | 후렴 |
|---|---|---|---|---|
| 구름 마을 | 기본, 할머니 댁 | 통통이 구름 (eunwoo) | 무지개 다리, 바람 언덕, 별 우물 | "통통 구름아, 어디로 갈까?" |
| 바다 왕국 | 바다, 해수욕장, 아쿠아리움 | 찰방이 아기 고래 (seoyoon) | 산호 숲, 진주 동굴, 파도 성 | "찰방찰방, 바다가 부른다!" |
| 공룡 섬 | 놀이공원, 동물원, 산 | 쿵쿵이 아기 공룡 (sanghyeok) | 화산 언덕, 큰 나무 숲, 알 둥지 | "쿵쿵, 공룡 발자국 따라!" |
| (P2) 우주 정거장 | 밤길, 긴 여행 | 반짝이 로봇 | 달 정류장, 별똥별 길 | |

**팩 하나에 정할 것** (JSON 파일, `app/src/main/assets/worlds/`)
- 세계 설명 3줄, 길잡이 캐릭터(이름, 말투, 목소리, 말버릇)
- 장소 목록 10개와 각 장소의 소리 묘사 예시
- 도로 이벤트별 장면 변환 (1-5절 표를 팩에 맞게)
- 쓰면 안 되는 것 (팩별 추가 금지어)
- 예시 장 1개 (프롬프트 few-shot에 사용)

**팩 고르는 규칙**: 목적지 종류(`PlaceKind`) → 팩. 직전 여정과 같은 팩이면 다른 팩 우선 (반복 피로 방지).

### 1-7. LLM 프롬프트 설계

**구성** (`story/PromptBuilder.kt`)

| 부분 | 내용 | 바뀌는 빈도 |
|---|---|---|
| 시스템 | 역할, 1-1 원칙, 금지 소재, 출력 JSON 형식 | 고정 (캐시 대상) |
| 세계관 팩 | 팩 설명, 캐릭터, 장소, 예시 장 1개 | 여정마다 |
| 연령 규칙 | 1-2 표의 해당 열 | 여정마다 |
| 이야기 노트 | 1-8절 (등장인물, 지금 장소, 남은 떡밥, 앞 장 마지막 2문장) | 장마다 |
| 지금 상황 | 남은 시간, 시간대, 비, 이번 장에서 꼭 넣을 이벤트 | 장마다 |
| 요청 | "N장을 써라, 결말 여부" | 장마다 |

**설정**
- JSON만 받도록 제공사의 구조화 출력(JSON schema) 기능을 씀. 없으면 파서가 코드 블록을 벗겨 냄 (이미 구현)
- 출력 길이 상한: 장 하나 약 800 토큰 [가정]
- 고정 부분(시스템 + 팩)은 앞에 두어 제공사의 프롬프트 캐시 혜택을 받음
- 제공사: 1차는 비용 0원인 Gemini 무료 등급 후보. 단 무료 등급은 입력이 Google 제품 개선에 쓰일 수 있어 서비스 단계에서는 유료 등급. Claude Haiku 5.5도 후보 (`01_기획서.md` 7장)

**선생성**
- 다음 장은 지금 장이 90초 남았을 때 요청 (이미 구현). 응답 시간 측정 후 조정
- 터널 등 예고 이벤트는 1km 전 생성 (이미 구현)
- 출발 직후 대기를 줄이려고 1장은 짧게, 뼈대와 함께 받음

### 1-8. 이야기 노트 (기억)

장마다 LLM이 앞 내용을 잊지 않게 짧은 노트를 같이 보냅니다.

```json
{
  "characters": [{"name": "{주인공}", "state": "통통이 위에 탐"}, {"name": "통통이", "state": "조금 지침"}],
  "place": "무지개 다리",
  "items": ["반짝이는 조개"],
  "open_threads": ["바다 왕국 문을 여는 열쇠 찾기"],
  "refrain": "통통 구름아, 어디로 갈까?",
  "last_lines": ["다리 끝에 작은 문이 보였어요.", "문에는 조개 모양 구멍이 있었어요."]
}
```

- LLM이 장마다 `summary`와 함께 노트 갱신분을 돌려줌 → 앱이 합쳐 다음 요청에 넣음
- 노트에도 실제 이름은 넣지 않음 (`{주인공}`)

### 1-9. 품질 평가 (P1)

**평가셋**: 목적지 종류 5 × 날씨 2 × 시간대 2 × 연령 3 중 30개 조합

**자동 검사 (코드로)**
| 검사 | 기준 |
|---|---|
| 문장 길이 | 연령 기준 이하 비율 95% 이상 |
| 금칙어 | 0건 |
| 주인공 호명 | 장당 1~3회 |
| 효과 태그 | 장당 2개 이하, 허용 종류만 |
| 결말 | 마지막 장에 결말 장소 이름 포함 |
| 형식 | JSON 파싱 성공률 99% 이상 |

**사람 평가 (팀원 2명이 1~5점)**
- 아이가 좋아할까, 따라 말할 후렴이 있나, 앞뒤가 이어지나, 길과 연결되나, 무섭거나 이상한 데 없나
- 프롬프트를 바꿀 때마다 같은 30개로 다시 재서 점수 비교

### 1-11. 데모 이야기 3편 (P0)

제출용 APK는 키가 없어 데모 이야기로만 돕니다. 심사위원이 듣는 건 이 3편입니다.

| 편 | 세계관 | 길이 | 들어갈 장면 |
|---|---|---|---|
| 1 | 구름 마을 → 할머니 댁 | 5장 | 비, 터널, 도착 |
| 2 | 바다 왕국 → 바다 | 6장 | 요금소, 비 그침, 도착 |

- 각 편은 1-3 구조, 1-2 연령 기준(6~7세)을 지킴
- 끼어들기 조각(터널, 요금소, 휴게소, 비 시작·그침, 해 짐)도 편마다 따로 씀
- 형식은 LLM 출력 JSON과 같게 → `assets/stories/`에 두고 `DemoStoryGenerator`가 읽음

## 2. 소리 디자인 (이 앱의 "화면")

### 2-1. 목소리 배정

| 역할 | 화자 | 규칙 |
|---|---|---|
| 해설 | haeun | 기본 |
| 길잡이 캐릭터 | 세계관 팩에서 지정 | 팩 안에서 고정 |
| 조연 1 | 남은 화자 중 하나 | 해설과 다른 화자 |
| 조연 2 | 남은 화자 | 3명 넘으면 해설이 대신 읽음 |

- 한 문장 안에서 화자를 바꾸지 않음. 대사와 해설은 문장을 나눔
- 말투 조절(속도, 높낮이)은 SDK 지원 여부 **[확인 필요]**

### 2-2. 고정 멘트

| 시점 | 문구 (예) |
|---|---|
| 재생 시작 | "달리는 동화, 오늘의 모험이 시작돼요." |
| 생성 대기 | "{주인공}, 준비됐나요? 귀를 쫑긋 세워 봐요." |
| 장 시작 | 짧은 징글 + "○장, 무지개 다리" (P1) |
| 일시정지 후 재개 | "다시 이야기를 이어 갈게요." |
| 도착 | "오늘의 모험은 여기까지예요. 다음 여행에서 또 만나요." |

### 2-3. 효과음과 배경음 (P1)

| 장면 태그 | 소리 | 쓰는 곳 |
|---|---|---|
| `rain` | 빗소리 | 비 장면 |
| `wind` | 바람 | 풍량 효과와 같이 |
| `cave` | 동굴 울림 | 터널 |
| `sea` | 파도 | 바다 왕국 |
| `forest` | 새소리 | 숲 |
| `chime` | 반짝 소리 | 독서등 효과, 장 전환 |

- LLM 출력 문장에 `sound` 태그를 추가로 받음 (효과 태그와 같은 방식)
- 배경음은 낭독보다 작게(낭독 중 자동으로 줄임), 장 끝나면 서서히 줄임
- 파일: OGG, 짧은 반복용 10~30초, 앱 용량 5MB 이내 목표
- **라이선스**: 직접 녹음했거나 상업적 이용 가능(CC0 등)한 것만. 출처를 README에 기록
- 내비 안내가 나오면 배경음도 같이 멈춤 (오디오 포커스, 이미 구현된 일시정지 흐름)

## 3. 4D 효과 연출

### 3-1. 지금 쓸 수 있는 효과와 조건 (에뮬레이터 확인)

| 풍량 +1단 | 됨 | 됨 | 됨 | 안 함 |

### 3-2. 연출 규칙 (P0~P1)

| 규칙 | 값 [가정] | 이유 |
|---|---|---|
| 효과 시작 | 효과 문장을 읽기 시작할 때 | 소리와 몸 느낌이 같이 와야 함 |
| 지속 | 풍량 20~60초, 독서등 10~30초 | 너무 길면 운전자 불편 |
| 쿨다운 | 같은 효과 사이 최소 3분 | 자주 바뀌면 산만 |
| 장당 최대 | 2개 | |
| 이벤트 즉시 효과 | 비 시작 → 바로 풍량 (LLM 응답 안 기다림) | "차가 이야기를 안다"는 느낌 (P0, `StoryDirector.surprise()`에 구현) |
| 끝나면 | 원래 값으로 (AUTO 포함) | 이미 구현 |

### 3-3. 장면 → 효과 사전 (LLM 지시와 자동 매핑에 공용)

| 반짝, 불빛, 램프, 반딧불, 햇살 (정차 중일 때만) | 독서등 |

- LLM이 태그를 빼먹어도 문장에 키워드가 있으면 앱이 붙일지 검토 (P1)

## 4. 화면과 디자인

앱 전용 화면은 없지만, **차 미디어 화면에 보이는 것**이 이 앱의 얼굴입니다. 심사위원과 시연 영상이 보는 것도 이 화면입니다.

### 4-1. 미디어 화면에 보이는 요소

| 요소 | 지금 | 고도화 | 단계 | 코드 |
|---|---|---|---|---|
| 앱 아이콘 | 안드로이드 기본 재생 아이콘 | 전용 아이콘 (구름 + 길) | P0 | `res/mipmap`, `AndroidManifest` |
| 앱 이름 | 달리는 동화 | 확정 이름 | P0 | `strings.xml` |
| 탭 | "이야기" | "오늘의 여정", "지난 이야기"(P2) | P1 | `StoryMediaService.onLoadChildren` |
| 목록 항목 | "출발하며 듣기" + 음표 아이콘 | 그림 아이콘, 부제에 목적지 ("강릉 경포해변까지 2시간 30분") | P0 | `MediaDescriptionCompat.setIconUri` |
| 재생 카드 (지금 재생 중) | 비어 있음 ("재생 중인 항목 없음") | 제목 = 장 제목, 부제 = 이야기 제목, 그림 = 장면 그림 | **P0** | `MediaMetadataCompat` 갱신 |
| 진행 | 없음 | "3장 / 7장" 또는 남은 시간 | P1 | 메타데이터 부제 |
| 재생 버튼 | 재생, 일시정지 | + 다음 장 | P1 | `onSkipToNext` |
| 커스텀 버튼 | 없음 | "효과 끄기", "새 이야기" | P1 | `PlaybackStateCompat.CustomAction` |

- 화면 문구는 짧게 (운전자가 한눈에), 주행 중 움직이는 그림 없음 (Pleos 규제)
- 재생 카드 그림은 정지 이미지만

### 4-2. 브랜드

| 항목 | 정할 것 |
|---|---|
| 이름 | "달리는 동화"(가칭) 확정 |
| 로고 | 구름 위 작은 자동차, 단순한 선. 64px에서도 알아볼 수 있게 |
| 색 | 하늘 파랑 + 따뜻한 노랑 2색 중심 (Pleos 화면이 흰 바탕이라 대비 확인) |
| 캐릭터 | 길잡이 "통통이 구름"을 대표 캐릭터로 (아이콘, 재생 카드 기본 그림) |
| 말투 | 존댓말, 짧게, 다정하게 ("~해요") |

### 4-3. 장면 그림

- 세계관 팩마다 장면 그림 6~10장 + 대표 그림 1장
- 크기: 정사각 512×512 이상, PNG/WebP, 앱 안에 포함 (오프라인)
- 장 메타데이터에 장소 키로 연결 (`place` → 그림 파일)
- **저작권**: 직접 그리거나, 생성형 이미지 도구로 만들 때 해당 도구의 상업적 이용 조건 확인. 기존 캐릭터와 닮지 않게
- 스타일 통일: 둥근 선, 파스텔 톤, 글자 없음

### 4-4. 주차 중 설정 화면 (P2, 2차 이후)

지금은 화면 없이 가지만, 실제 서비스에는 아이 등록이 필요합니다. 주차 중에만 여는 설정 화면 하나를 둡니다.

| 화면 | 내용 |
|---|---|
| 아이 등록 | 이름(호칭), 나이, 자리, 카시트 여부, 좋아하는 것 3개 |
| 보호자 동의 | 외부 AI로 보내는 정보 고지 |
| 효과 설정 | 바람, 빛 각각 켜기·끄기 |
| 세계관 | 자동 / 직접 고르기 |
| 지난 이야기 | 제목 목록, 다시 듣기 |

- 큰 버튼, 한 화면에 3개 이하 선택, 주행 시작하면 자동으로 닫힘 (Pleos 주행 규제)

### 4-5. 시연 영상 디자인 (P0)

| 구간 | 화면 | 소리 |
|---|---|---|
| 0~15초 | 문제: 뒷좌석 아이, 지루함 (자막) | |
| 15~30초 | 미디어 화면에서 출발하며 듣기 | 도입 멘트 |
| 30~90초 | 차 화면 + Virtual Console 나란히. 비, 터널 주입 | 끼어들기 낭독 |
| 90~120초 | 바람 장면에서 풍량 3 → 4, 정차 장면에서 독서등 | 효과 문장 |
| 120~150초 | 같은 출발지에서 목적지만 바꿔 다른 이야기 | 두 이야기 비교 |
| 150~180초 | 도착, 결말, 효과 복귀 | 결말 멘트 |

- 화면 녹화 + 자막. 얼굴과 실명은 넣지 않음 (블라인드)
