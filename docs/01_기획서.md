# 기획서: 달리는 동화 (가칭)

> 최종 수정 2026-11-12 / 접수양식 1~8번 작성의 기준 문서
> 표시: **[결정]** 팀이 정한 것, **[가정]** 임시로 정한 것, **[확인 필요]** 아직 검증하지 않은 것

---

## 1. 한 줄 소개

**지금 달리는 길이 그대로 이야기가 되는 차량용 4D 오디오 동화.** 목적지와 남은 시간, 날씨, 터널 같은 실제 도로 상황을 실시간으로 이야기에 넣고, 장면에 맞춰 아이 자리의 독서등과 바람이 반응합니다.

## 2. 기획 배경 (Pain Point)

| 문제 | 근거 |
|---|---|
| 주행 중 뒷좌석 아이가 지루해하면 휴대폰 영상을 쥐여 주는 경우가 많음 **[가정: 차 안 영상 시청 통계 없음]** | 유아동(만 3~9세) 스마트폰 과의존 위험군 26.0% (과기정통부 2025 실태조사, 머니투데이 2026-03-27) |
| Pleos 차량 화면은 주행 중 동영상 금지 | Pleos 주행 규제 정책 (Pleos 개발 문서) |
| 휴대폰 오디오 동화는 지금 이 차가 어디로, 얼마나, 어떤 길로 가는지 모름 | 정해진 이야기를 재생할 뿐, 차량 데이터에 접근할 수 없음 |
| 템플릿 동화는 매번 같아지고, 소리만으로는 몰입이 약함 | 팀 내부 검토 (이전 기획안의 한계) |

**정리:** 주행 중 차가 아이에게 줄 수 있는 것은 소리와 실내 환경뿐인데, 지금은 그 둘을 이번 여정에 맞춰 쓰는 앱이 없음.

## 3. 타깃

- **주 사용자:** 4~9세 아이를 태우고 이동하는 30~40대 부모 운전자 **[가정: 아이 나이 범위]**
- **보조 사용자:** 손주를 태우는 50~60대 조부모 운전자
- **사용 상황:** 주말 나들이와 여행(1시간 이상), 본가 방문, 명절, 평일 등원·학원 이동(짧은 한 편)

| 근거 | 출처 |
|---|---|
| Pleos Connect는 2026년 5월 더 뉴 그랜저 첫 탑재, 디 올 뉴 아반떼 기본 적용, 2030년 약 2,000만 대 목표 | 디지털데일리 2026-05-14, ZDNet 2026-08-05, 머니투데이 2026-04-30 |
| 그랜저 6월 개인 구매자 3,416명 중 30~40대 31.7%, 50~60대 65.8% | 다음 2026-07-10 (기사 대수로 계산) |
| 55~74세 조부모의 손자녀 돌봄 평일 주 4.6일 | 한국여성정책연구원 2025 (파이낸셜뉴스 2026-04-28) |

## 4. 핵심 가치와 동작

**핵심 가치 하나:** 이번 여정이 그대로 이야기가 되고, 차가 그 이야기를 몸으로 느끼게 해 줌 **[결정]**

### 4-1. 실시간 이야기 생성 (세 층 구조) [결정]

이야기를 출발 전에 통째로 만들지 않습니다. 그러면 가는 도중에 생기는 비, 터널, 정체를 반영할 수 없기 때문입니다.

| 층 | 언제 | 무엇을 | 반영하는 상황 |
|---|---|---|---|
| 1층 뼈대 | 출발할 때 | 전체 줄거리, 등장인물, 결말 장소(목적지), 장 계획, 1장 | 목적지, 남은 시간, 시간대, 출발 시 비 |
| 2층 다음 장 | 지금 장이 끝나기 1~2분 전 | 다음 한 장 | 그 순간의 비, 밤, 정체, 남은 시간 (남은 시간에 따라 장 수 조절) |
| 3층 끼어들기 | 도로 이벤트가 생길 때 | 1~3문장 | 예고되는 이벤트(터널, 요금소, 휴게소)는 내비가 알려 주는 거리로 **미리** 생성해 두고 진입 순간 재생. 예고 없는 이벤트(비 시작)는 그 순간 생성 |

- 터널 안에서는 통신이 끊기기 쉬워서 터널 장면은 반드시 진입 전에 만들어 둠
- 생성이 늦거나 실패하면 미리 준비한 범용 문장으로 대체 ("어? 하늘에서 빗방울이 톡톡!")
- **효과는 LLM을 기다리지 않음.** 이벤트를 받으면 앱이 바로 독서등·바람을 실행하고, 이야기 문장은 뒤따라 나옴
- 낭독 중에 이벤트가 오면 지금 문장을 끝까지 읽고 다음 자리에 끼워 넣음. 그래서 문장을 짧게 생성함

### 4-2. 4D 효과 (1차) [결정]

| 효과 | 장면 예시 | 주행 중 규칙 |
|---|---|---|
| 낭독 화자 바꾸기 | 해설, 주인공, 조연을 다른 목소리로 (Pleos TTS 화자 4명) | 제한 없음 |
| 효과음 | 파도, 바람, 새소리 | 제한 없음 |
| 아이 자리 독서등 켜기·끄기 | 반딧불, 마법 램프, 아침 햇살 | **정차 중에만** (주행 중에는 차량이 독서등 제어를 거부함, 에뮬레이터 확인). 전조등 켜짐이면 사용 안 함, 최대 30초 |
| 풍량 한 단계 올리기 | 바람 행성, 바닷바람 | +1단, 최대 1분, 공조가 꺼져 있으면 사용 안 함, 끝나면 원래 값(AUTO 포함)으로 복귀 |

- 운전석 온도와 시트는 바꾸지 않음
- 내비 음성 안내가 나오면 동화 소리를 줄이고 효과를 멈춤
- 뒷좌석 시트 열선·통풍, 뒷좌석 전용 소리, 블라인드는 지원 차량에서의 확장 기능 (에뮬레이터에는 없음)

### 4-3. 화면 없이 쓰기 [결정]

- 앱 전용 화면을 만들지 않음. 차의 기본 미디어 화면에 "달리는 동화"가 일반 오디오 앱처럼 나타남 (MediaSession)
- 시작: 미디어 화면의 재생 버튼 또는 핸들 재생 버튼. Pleos는 오디오 앱의 자동 재생을 금지하므로 부모가 눌러야 시작함
- 아이 정보: 1차는 설정 파일의 시연용 프리셋, 2차에 음성 등록
- 주행 중 조작은 핸들 버튼(재생·일시정지·다음 장)과 음성만

## 5. 사용 시나리오

**토요일 오후, 38세 부모가 6살 하윤이를 태우고 강릉 바다로 감 (2시간 30분, 출발할 때 비)**
1. 내비에 "강릉 경포해변" 설정, 미디어 화면에서 "달리는 동화" 재생
2. 고정 도입부 "오늘의 모험이 시작돼요"가 나오는 동안 뼈대와 1장 생성 (목적지, 2시간 30분, 비, 낮)
3. 1장 "비 내리는 구름 마을". 실제로 와이퍼가 움직이는 중
4. 내비가 "1.2km 앞 터널"을 알려 줌 → 동굴 장면을 미리 생성 → 진입 순간 "반짝이는 동굴에 들어갔어요"
5. 비가 그침 → 다음 장은 "햇살이 비치는 들판"으로 생성
6. "바람 행성" 장면에서 풍량이 한 단계 올라감 1분 → "우와, 바람이 분다!"
7. "반딧불 숲" 장면에서 하윤이 자리 독서등이 30초 켜졌다 꺼짐 (낮)
8. 도착 3분 전 결말: "드디어 파란 바다 왕국, 경포해변에 도착했어요!" → P → 효과 원래대로

## 6. 차량특화성: 휴대폰으로는 안 되는 것

| 필요한 것 | 휴대폰 오디오 동화 | 달리는 동화 |
|---|---|---|
| 목적지, 남은 시간 | 모름 | NaviHelper 목적지 정보 |
| 앞에 터널, 요금소가 있는지 | 모름 | NaviHelper 턴바이턴 (`TURN_TUNNEL`, `TURN_TOLL`) |
| 비, 밤 | 모름 | Vehicle 와이퍼, 전조등 |
| 출발, 도착 | 추정만 | 기어 P/D |
| 아이가 어느 자리에 탔는지 | 모름 | 좌석 착석, 도어 |
| 독서등, 바람 | 못 바꿈 | Vehicle Light, HVAC |

## 7. 기술 구조 요약

- 자세한 내용은 `docs/02_구조설계.md`, 모듈 간 형식은 `docs/03_모듈간_약속.md`
- Pleos SDK: Vehicle 2.3.2, NaviHelper 3.0.5, TextToSpeech 3.3.1
- LLM: 외부 API **[결정]**. 제공사는 미정
  - 후보 1: Google Gemini 무료 등급. 1차 개발·시연 비용 0원. 단 무료 등급은 입력·출력이 Google 제품 개선에 쓰일 수 있어 서비스 단계에서는 유료 등급 필요
  - 후보 2: Claude Haiku 5.5 (입력 100만 토큰당 $0.10, 출력 $0.50, 2026-10 기준)
- 판단(언제 생성하고 언제 효과를 낼지)은 앱의 규칙. LLM은 문장과 효과 태그만 만들고 차를 직접 조작하지 않음

## 8. 아이 안전과 개인정보

- 아이 이름은 기기 밖으로 보내지 않음. LLM에는 `{주인공}` 자리표시만 보내고 받은 문장을 기기 안에서 치환
- 나이는 연령대(4~5 / 6~7 / 8~9세)만, 목적지는 공개 장소명만 전송. 주소·좌표는 보내지 않음
- 보호자 고지와 동의: 외부 AI로 보내는 정보(연령대, 목적지 장소명, 남은 시간, 시간대, 날씨·도로 상황) **[확인 필요: 만 14세 미만 아동 정보, 국외 이전 요건]**
- 금지 소재(죽음, 폭력, 길을 잃음 등), 목적지 허용 목록(장례식장·병원 등은 목적지 이름을 쓰지 않고 일반 결말), 기기 안 금칙어 검사
- 생성 실패, 거절 응답, 검사 실패 시 기본 이야기로 대체

## 9. 사업성

- **이용료 무료.** 차량 기능 구독에 약 75%가 지불 의향 없음 (BGR 2026-11-01, 원 조사 연도 미확인)
- **비용 [가정]:** 여정 1회 = 뼈대 1회 + 장 약 10회 + 끼어들기 약 5회. 호출당 입력 약 1,500 토큰, 출력 약 500 토큰이면 Haiku 5.5 기준 여정당 약 $0.006 (약 8원, 1,400원/$)
- **수익 [가정]:** 캐릭터 IP 이야기 팩, 목적지 제휴(놀이공원·아쿠아리움 가는 길 이야기), 현대차의 가족 고객 차별 기능
- **예상 MAU (그랜저 10만 대당)**
  | 항목 | 값 | 근거 |
  |---|---|---|
  | 개인 구매 비중 | 35% | 그랜저 6월 개인 구매 3,416 / 집계 9,741 **[확인 필요: 집계 기준]** |
  | 개인 구매자 중 30~40대 | 31.7% | 같은 자료 |
  | 4~9세 아이가 있는 가구 | 50% | **[가정]** |
  | 잠재 이용자 | 약 5,500가구 | 10만 × 0.35 × 0.317 × 0.5 |
  | 월 활성 비율 | 10% / 30% / 60% | **[가정]** 직접 설치 / 앱마켓 추천 / 기본 탑재 |
  | **MAU** | **약 550 / 1,700 / 3,300가구** | |
- **Retention 목표 [가정]:** 다음 달 재방문율 40%. 월 1회 이상 차로 여행할 확률 약 42%(2025 국민여행조사 연 6.5회로 계산)에 평일 짧은 이동이 더해진다는 가정
- **확대:** 지금 탑재 차는 50~60대 중심이라 숫자가 작음. 가족용 SUV 탑재 확대가 성장 근거, 조부모 운전자는 보조 사례

## 10. 1차(11/15)와 2차(12/3) 범위

| 항목 | 1차 | 2차 |
|---|---|---|
| 이야기 생성 | 뼈대 + 다음 장 + 터널·비 끼어들기, 안전 검사, 기본 이야기 대체. 제출 APK는 키 없는 데모 모드 | 요금소·휴게소·정체·해 짐 끼어들기, 이어지는 시즌, 아이 음성 선택 |
| 이야기 재료 | 목적지, 남은 시간, 시간대, 비(와이퍼), 터널, 도착 | 날씨 예보, 지역 명소, 아이 취향 |
| 4D 효과 | 독서등, 풍량, 화자 바꾸기, 효과음 | 지원 차량의 시트 열선·통풍, 뒷좌석 전용 소리 |
| 조작 | 미디어 화면 재생, 핸들 버튼 | 음성 |
| 시연 | 시연용 이벤트 주입(모의 주행은 앱에서 시작할 수 없음) | 현장 시연 |

## 11. 위험과 대응

| 위험 | 대응 |
|---|---|
| 한국 주행 규제에서 "차량 설정"이 주행 중 금지라 앱의 공조·조명 제어가 막힐 수 있음 **[확인 필요]** | 에뮬레이터에서 `driving_regulation on`으로 먼저 확인. 막히면 효과는 정차 중에만, 주행 중은 소리만 |
| 실시간 생성 지연, 터널 등 통신 끊김 | 다음 장은 1~2분 앞서 생성, 예고 이벤트는 미리 생성, 범용 문장과 기본 이야기로 대체 |
| 생성 이야기가 아이에게 부적절 | 금지 소재, 허용 목록, 금칙어 검사, 대체 |
| API 키 노출 | 키는 `local.properties`에만, 제출 APK는 데모 모드 |
| 오디오 앱 요건(MediaSession, 핸들 키, 오디오 포커스) 미충족 시 주행 중 사용 불가 | 1차 범위에 포함 |
| 아이 정보 외부 전송 | 이름 미전송, 연령대만, 보호자 고지 |
