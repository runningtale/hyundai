## 1. 공통 데이터 (`model/`)

| 타입 | 필드 | 설명 |
|---|---|---|
| `ChildProfile` | `name`, `ageBand`, `seat`, `usesCarSeat` | `name`은 기기 밖으로 보내지 않음 |
| `AgeBand` | `AGE_4_5`, `AGE_6_7`, `AGE_8_9` | LLM에는 이 값만 전송 |
| `SeatPosition` | `REAR_LEFT`, `REAR_CENTER`, `REAR_RIGHT` | Pleos `SeatValue.ROW_2_*`에 대응 |
| `PlaceKind` | `SEA`, `MOUNTAIN`, `PARK`, `AMUSEMENT`, `FAMILY_HOME`, `HOME`, `RESTAURANT`, `LODGING`, `SCHOOL`, `OTHER`, `BLOCKED` | 목적지 이름 키워드로 기기 안에서 분류. 금지 장소(장례식장, 병원 등)는 `BLOCKED`, 어느 키워드에도 안 맞으면 `OTHER`. 두 경우 모두 목적지 이름을 LLM에 보내지 않고 일반 결말 |
| `TimeOfDay` | `MORNING`, `DAY`, `EVENING`, `NIGHT` | 기기 시각 + 전조등 |
| `TripState` | `destinationName`, `placeKind`, `remainSec`, `timeOfDay`, `isRaining`, `isHeadlightOn`, `isMoving` | Director가 최신 상태를 유지 |
| `Voice` | `SEOYOON`, `EUNWOO`, `HAEUN`, `SANGHYEOK` | Pleos TTS 한국어 화자 |
| `EffectType` | `READING_LIGHT`, `FAN` | 1차 효과 2종 |
| `Effect` | `type`, `level`(1 고정), `durationSec` | 독서등 최대 30초, 풍량 최대 60초 |
| `StoryLine` | `speaker`, `text`, `effect?` | `speaker`는 `narrator` 또는 등장인물 이름 |
| `Chapter` | `index`, `title`, `lines`, `summary`, `isFinal` | `summary`는 다음 생성에 넘길 줄거리 |
| `StoryCharacter` | `name`, `voice`, `role` | |
| `StorySkeleton` | `title`, `world`, `characters`, `endingPlace`, `chapterPlan`, `firstChapter` | |
| `InterludeTrigger` | `TUNNEL`, `TOLL`, `REST_AREA`, `RAIN_START`, `RAIN_STOP`, `NIGHT_FALL` | |
| `Interlude` | `trigger`, `lines` | 1~3문장 |

## 2. 주행 이벤트 (`DriveEvent`) [담당 2 → 담당 3]

`VehicleGateway`, `NaviGateway`가 `Flow<DriveEvent>`로 내보내고 `StoryDirector`가 받습니다.

| 이벤트 | 필드 | 보내는 곳 | 출처 API |
|---|---|---|---|
| `GearChanged` | `gear: Gear` (`PARK`, `DRIVE`, `REVERSE`, `NEUTRAL`, `UNKNOWN`) | VehicleGateway | `Gear.registerGearSelection` |
| `RearSeatChanged` | `seat`, `occupied` | VehicleGateway | `Seat.registerSeatOccupancy(SeatArea(ROW_2_*))` |
| `RearDoorChanged` | `seat`, `open` | VehicleGateway | `Door` 열림 (카시트 자리 탑승 판단용) |
| `RainChanged` | `raining` | VehicleGateway | `Wiper.registerWiperState(WindowArea(FRONT_WINDSHIELD))` |
| `HeadlightChanged` | `on` | VehicleGateway | `Light.registerLowBeamLightState` |
| `DestinationUpdated` | `name`, `remainSec` | NaviGateway | `onDestinationInfo` |
| `RoadEventAhead` | `trigger`(`TUNNEL`, `TOLL`, `REST_AREA`), `distanceM` | NaviGateway | `onTBTInfo` (`TURN_TUNNEL`, `TURN_TOLL`, `TURN_ENTER_SERVICEAREA`, `TURN_RESTAREA`). 1km 안일 때만 보냄 |
| `Arrived` | 없음 | NaviGateway | `onDestinationArrived` |

## 3. 이야기 생성 [담당 1 → 담당 3]

```kotlin
interface StoryGenerator {
    suspend fun createSkeleton(child: ChildProfile, trip: TripState): StorySkeleton
    suspend fun nextChapter(skeleton: StorySkeleton, storySoFar: String, trip: TripState, index: Int, isFinal: Boolean): Chapter
    suspend fun interlude(skeleton: StorySkeleton, storySoFar: String, trigger: InterludeTrigger, trip: TripState): Interlude
}
```

- 실패하면 예외를 던지지 않고 `FallbackLines`의 기본 문장으로 채워서 반환합니다 (Director가 예외 처리를 몰라도 되게)
- 반환되는 문장의 `{주인공}`은 이미 아이 이름으로 바뀐 상태입니다

### LLM 응답 JSON 형식

LLM에게는 아래 형식만 출력하라고 지시합니다. 키는 snake_case입니다.

**뼈대 (`createSkeleton`)**
```json
{
  "title": "구름 마을의 바다 왕국 여행",
  "world": "비가 자주 오는 구름 마을과 파란 바다 왕국",
  "characters": [
    {"name": "{주인공}", "voice": "haeun", "role": "주인공"},
    {"name": "통통이", "voice": "eunwoo", "role": "길잡이 구름"}
  ],
  "ending_place": "파란 바다 왕국",
  "chapter_plan": ["구름 마을 출발", "반짝이는 숲", "바람 행성", "바다 왕국 도착"],
  "first_chapter": { "...": "아래 장 형식" }
}
```

**장 (`nextChapter`, `first_chapter`)**
```json
{
  "index": 1,
  "title": "비 내리는 구름 마을",
  "lines": [
    {"speaker": "narrator", "text": "오늘은 {주인공}이 모험을 떠나는 날이에요."},
    {"speaker": "통통이", "text": "바람이 불어온다! 꽉 잡아!", "effect": {"type": "fan", "level": 1, "duration_sec": 40}}
  ],
  "summary": "주인공과 통통이가 구름 마을을 떠났다.",
  "is_final": false
}
```

**끼어들기 (`interlude`)**
```json
{
  "trigger": "tunnel",
  "lines": [
    {"speaker": "narrator", "text": "와, 반짝이는 동굴에 들어왔어요!"}
  ]
}
```

- `effect.type`: `reading_light` 또는 `fan`만 허용. 그 외는 버림
- 문장 하나는 40자 이내 (낭독 중 끼어들기를 위해 짧게)
- 장 하나는 문장 8~15개

### 데모 이야기 파일 [이야기 팀 → 앱]

API 키가 없는 제출용 APK는 `app/src/main/assets/stories/` 폴더의 JSON 파일을 읽어 재생합니다 (`DemoStoryGenerator`). 이야기 팀은 파일만 넣으면 되고 코드는 고치지 않습니다. 예시: `00_sample.json`

```json
{
  "id": "cloud_village",
  "places": ["FAMILY_HOME", "HOME"],
  "skeleton": { "...": "위 뼈대 형식 그대로 (first_chapter 포함)" },
  "chapters": [
    { "...": "2장, 장 형식" },
    { "...": "마지막 장, \"is_final\": true" }
  ],
  "interludes": {
    "tunnel": [{"speaker": "narrator", "text": "와, 반짝이는 동굴에 들어왔어요!"}],
    "toll": [], "rest_area": [], "rain_start": [], "rain_stop": [], "night_fall": []
  }
}
```

| 키 | 내용 |
|---|---|
| `id` | 로그에 찍히는 이름. 영어 소문자 |
| `places` | 이 이야기를 고를 목적지 종류. `SEA`, `MOUNTAIN`, `PARK`, `AMUSEMENT`, `FAMILY_HOME`, `HOME`, `RESTAURANT`, `LODGING`, `SCHOOL`, `OTHER` 중에서 (분류 키워드는 `SafetyFilter.kt`) |
| `skeleton` | 뼈대. 1장은 `first_chapter`에 |
| `chapters` | 2장부터 결말까지 순서대로. 마지막 장만 `is_final: true` (앱은 파일 값과 상관없이 마지막 장을 결말로 처리) |
| `interludes` | 끼어들기 키별 1~3문장. 없는 키는 기본 문장(`FallbackLines`)으로 대체 |

- 고르는 순서: `places`에 지금 목적지 종류가 있는 첫 파일 → 없으면 파일 이름순 첫 파일. 그래서 기본으로 쓸 이야기는 파일 이름을 `00_`으로 시작합니다
- 목적지는 재생을 누를 때 기준입니다. 도착 후 다시 재생하면 그때 목적지로 다시 고릅니다
- 여정이 이야기보다 짧으면 중간 장을 건너뛰고 결말로 갑니다. 여정이 더 길면 결말 뒤에는 도착까지 조용히 기다립니다
- `{주인공}`은 그대로 두면 앱이 아이 이름으로 바꿉니다
- 파일 형식이 틀리면 그 파일만 건너뛰고 로그를 남깁니다: `adb logcat -s DemoStoryGenerator`

## 4. 효과 실행 [담당 3 → 담당 2]

```kotlin
class EffectController {
    fun start()                                                              // 공조 구역과 현재 상태(전원, AUTO, 풍량) 구독
    fun apply(effect: Effect, seat: SeatPosition, trip: TripState): Boolean  // 실행했으면 true, 규칙에 걸리면 false
    fun restoreAll()                                                         // 바꾼 값 전부 원래대로
}
```

| 규칙 | 내용 |
|---|---|
| 운전석 불변 | 운전석 온도, 시트는 건드리지 않음 |
| 독서등 | 아이 자리(`ROW_2_*`)만. 정차 중에만 (주행 중에는 차량이 거부함, 에뮬레이터 확인). `trip.isHeadlightOn`이어도 실행 안 함. 최대 30초 후 자동 끔 |
| 풍량 | 공조가 꺼져 있으면 실행 안 함. 현재 값 +1단, 최대 60초 후 원래 값으로. AUTO였으면 AUTO로 되돌림 |
| 동시 실행 | 같은 종류의 효과가 실행 중이면 새 요청은 무시 |
| 쿨다운 | 같은 종류는 마지막 실행 후 3분(`AppConfig.EFFECT_COOLDOWN_SEC`) 동안 무시. 효과가 2종이라 장당 최대 2개도 같이 지켜짐 |
| 즉시 효과 | 비가 오기 시작하면 생성 응답을 기다리지 않고 바로 풍량 20초 (`StoryDirector.IMMEDIATE_EFFECTS`) |
| 내비 안내 중 | Director가 오디오 포커스를 잃은 동안에는 호출하지 않음 |

## 6. LLM 호출 [담당 1 내부]

```kotlin
interface LlmClient {
    suspend fun complete(systemPrompt: String, userPrompt: String): String  // JSON 문자열
}
```

- 제공사(Gemini, Claude 등)는 이 인터페이스 구현만 바꿔 끼움
- 키는 `BuildConfig.LLM_API_KEY` (`local.properties`의 `LLM_API_KEY`). 비어 있으면 데모 모드
- LLM에 보내는 정보: 연령대, 목적지 장소명(`BLOCKED`, `OTHER`면 보내지 않음), 장소 종류, 남은 시간(분), 시간대, 비 여부, 이야기 제목·세계·장 계획, 지금까지 줄거리 요약
- 보내지 않는 정보: 아이 이름(제목에도 넣지 않음, 받은 문장의 `{주인공}`만 기기 안에서 치환), 주소, 좌표
