## 범위

| 넣음 | 데모 모드에서 하는 일 |
|---|---|
| 이름(호칭) | 낭독 문장의 `{주인공}` 치환, 재생 카드 제목 |
| 앉는 자리 (뒷좌석 왼쪽 / 오른쪽) | 독서등을 켜는 자리. 가운데는 에뮬레이터 독서등이 좌·우만 있어(docs/04) 동작 근거가 없으므로 넣지 않음 |
| 바람 효과 켜기/끄기 | 끄면 풍량 효과 실행 안 함 |
| 빛 효과 켜기/끄기 | 끄면 독서등 효과 실행 안 함 |

넣지 않음: 나이(데모 모드에서 쓰이지 않음, `DemoStoryGenerator`가 읽지 않음), 카시트, 좋아하는 것, 보호자 동의, 세계관, 지난 이야기. 나이는 저장 모델에 DemoPreset 값(6~7세)을 그대로 두고 화면에는 보이지 않는다.

## 결정 1. 화면을 여는 곳

| 옵션 | 장점 | 단점 |
|---|---|---|
| A. 미디어 화면 "⋯" 메뉴의 앱 설정 (`APPLICATION_PREFERENCES` 액티비티) | 사용자 흐름이 자연스러움. Pleos 미디어 앱 dex에 해당 문자열이 있고 "⋯" 메뉴가 있음 (지금은 "사운드 설정"만 보임) | 항목이 실제로 생기는지 확인 필요 |
| B. 미등록이면 재생 상태를 ERROR로 두고 등록 버튼 | 첫 실행 안내 | `setState`가 재생, 일시정지, 포커스 변경마다 덮어씀. 버튼이 안 그려지면 재생이 막힘 |
| C. 런처 아이콘 | 확실함 | 흐름이 한 단계 늘어남 |

**결정:** A. B는 넣지 않는다. 미등록이면 DemoPreset으로 재생해서 첫 설치 상태에서도 "출발하며 듣기"가 막히지 않게 한다. A의 메뉴 항목이 에뮬레이터에서 안 생기면 C로 바꾸고, C를 쓸 때는 앱 아이콘을 눌렀을 때 미디어 화면이 아니라 설정이 열리는지 함께 확인한다.

## 결정 2. 저장 방식

**결정:** SharedPreferences를 감싼 `ChildStore(context)`. Context만으로 만들고 AppGraph와 독립 (액티비티는 서비스가 없을 때도 열릴 수 있음).

| 키 | 값 |
|---|---|
| `name` | 한글 1~6자. 없으면 미등록 |
| `seat` | `REAR_LEFT` 등 enum 이름 |
| `fan_enabled`, `light_enabled` | 기본 true |

`load()`는 등록 정보가 없으면 DemoPreset의 값을 돌려준다. 이름은 기기 밖으로 나가지 않는다 (기존 원칙). 이를 지키려고 매니페스트에 `android:allowBackup="false"`를 넣어 자동 백업 대상에서 뺀다.

## 결정 3. 반영 시점

- **이름, 자리:** `StoryDirector`가 `() -> ChildProfile`을 받고, `startStory()`에서 한 번 읽어 필드에 보관한다. 이름 치환, 재생 카드, 효과 자리, generator 호출에 모두 그 값을 쓴다. 이야기 도중에는 바뀌지 않는다.
- **새 이야기 시작:** `play()` 때 저장된 프로필이 보관 중인 값과 다르면 `reset()` 후 새 이야기를 시작한다 (일시정지 → 설정 변경 → 재생 = 새 이름의 새 이야기). 도착 후 재생하면 새 이야기가 되는 기존 동작은 그대로. 내비 안내·Gleo 뒤 자동 재개는 `resume()`으로 설정 변경을 보지 않고 이어 듣는다 (재생 중 변경이 주행 중 갑자기 새 이야기로 바뀌지 않게). `startStory()`의 뼈대 생성 Job을 보관해 `reset()`에서 취소한다 (옛 이름의 1장이 큐에 들어가는 경합 방지).
- **효과 켜기·끄기:** 즉시 반영. `EffectController.apply`가 실행할 때마다 읽는다. 이미 실행 중인 효과는 원래 타이머대로 복귀한다.

## 결정 4. 효과 끄기 위치

**결정:** `EffectController.apply` 맨 앞에서 확인. 생성자에 `isEnabled: (EffectType) -> Boolean`을 넘긴다. 효과 호출 2곳(`StoryDirector`의 문장 효과, 비 즉시 효과)이 모두 이 함수를 거친다. 꺼져 있으면 로그 `"$type 꺼짐(설정), 건너뜀"`을 남기고 false를 돌려준다. 쿨다운 기록도 남기지 않는다.

## 결정 5. 이름 뒤 조사

받침 없는 이름(예: 지우)에서 "지우은"이 되는 문제. `SafetyFilter`의 치환을 한곳으로 모으고 조사를 받침에 맞춰 고른다.

| 템플릿 | 받침 있음 (하윤) | 받침 없음 (지우) |
|---|---|---|
| `{주인공}은/는` | 하윤은 | 지우는 |
| `{주인공}이/가` | 하윤이 | 지우가 |
| `{주인공}을/를` | 하윤을 | 지우를 |
| `{주인공}과/와` | 하윤과 | 지우와 |
| `{주인공}으로/로` | 하윤으로 | 지우로 (ㄹ 받침도 로) |
| `{주인공}아/야` | 하윤아 | 지우야 |

템플릿에 어느 쪽 조사가 써 있어도 이름에 맞게 바꾼다. 조사 뒤가 한글이면(예: `{주인공}이에요`) 건드리지 않는다. 이 경우 "지우이에요"로 남는 한계가 있으므로 이야기 파일과 LLM 프롬프트에는 `{주인공}` 뒤에 위 6쌍의 조사, `의`, 공백, 문장부호, 문장 끝만 쓴다는 규칙을 docs/03에 적는다 (지금 에셋에는 해당 형태 없음). 입력을 한글 완성형 1~6자로 제한해 받침 판정이 항상 가능하게 한다. `StoryDirector.withName`도 같은 함수를 쓴다.

조사 함수는 Android 의존이 없는 순수 Kotlin 함수(`Josa.kt`)로 두고, `app/build.gradle.kts`에 `testImplementation("junit:junit:4.13.2")`를 추가해 `app/src/test/`에서 단위 테스트한다.

## 결정 6. 화면과 매니페스트

- `SettingsActivity`: 프레임워크 위젯과 XML 레이아웃 (AppCompat 없음). 테마 `@android:style/Theme.DeviceDefault.Light.NoActionBar`. 큰 글씨, 한 화면, 저장 버튼 하나. 저장하면 짧은 안내 후 닫힘
- 매니페스트: `exported="true"`, intent-filter `android.intent.action.APPLICATION_PREFERENCES` + `android.intent.category.DEFAULT`. `distractionOptimized` 메타데이터는 넣지 않음 (주행 중 사용 선언 없음)
- **주행 중 차단:** 공식 문서는 주행 중 사용 선언이 없는 앱 화면을 막는다고 한다 (docs/05 5장). **11/14 확인: 에뮬레이터는 막지 않음 → 대체안 채택.** 에뮬레이터에서 D + 속도 > 0 (Virtual Console 가속)으로 화면이 막히거나 닫히는지 확인한다. 안 막히면 액티비티가 `RunningTaleApp.graph`의 기어 이벤트를 구독해 D에서 `finish()`한다 (graph가 null이면 구독 건너뜀). 그래도 안 되면 영상과 기획서에 "주행 중 자동 차단"을 쓰지 않는다
