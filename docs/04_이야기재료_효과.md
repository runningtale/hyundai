# 이야기 재료와 효과 목록

> 최종 수정 2026-11-12 / 주행 중 기준. 화면과 주차 중 기능은 다루지 않음
> 단계: 1차(11/15 제출), 2차(12/3 PT), 확장(지원 차량), 제외 / 콘솔: 에뮬레이터 Virtual Console에서 값을 바꿀 수 있는지

## 1. 이야기 재료 (입력)

### 여정 (NaviHelper)
| 재료 | API | 이야기에서 | 콘솔 | 단계 |
|---|---|---|---|---|
| 목적지 이름 | `onDestinationInfo` → `name` (종류 필드 없음) | 마지막 장소. 이름 키워드로 `PlaceKind` 분류 | 내비 화면 | 1차 |
| 남은 시간, 거리 | `remainTime`(초), `remainDistance`(m) | 장 수, 결말 시점 | 내비 화면 | 1차 |
| 도착 | `onDestinationArrived` | 결말 마무리 | 내비 화면 | 1차 |
| 터널 | `onTBTInfo` → `TURN_TUNNEL` + 거리 | 동굴 | 이벤트 주입 | 1차 |
| 요금소 | `TURN_TOLL` | 성문 | 이벤트 주입 | 2차 |
| 휴게소, 졸음쉼터 | `TURN_ENTER_SERVICEAREA`, `TURN_RESTAREA` | 쉬어 가는 마을 | 이벤트 주입 | 2차 |
| IC, 갈림길, 지하차도, 고가 | `TURN_ENTER_IC_*`, `TURN_DEVIDE_MERGE`, `TURN_ENTER_UNDER_*`, `TURN_ENTER_OVER_*` | 큰길, 갈림길, 땅속 길, 하늘 다리 | 이벤트 주입 | 2차 |
| 주의 구간 | `onCautionPointInfo` (야생동물, 안개, 어린이보호구역, 과속방지턱) | 숲속 동물 친구, 통통 다리 | 이벤트 주입 | 2차 |
| 정체 | `RouteStateInfo.trafficStatus` | 덤 장면, 수수께끼 | 이벤트 주입 | 2차 |
| 제한속도 | `onCurrentRoadSpeedLimit` | 느린 숲길, 빠른 바람길 | 이벤트 주입 | 2차 |
| 지나는 지역 | `getCurrentLocationInfo` | "지금 대관령 근처예요" | | 2차 |
| 즐겨찾기, 최근 목적지 | `getBookmarkInfo`(HOME 등), `getRecentDestinationInfo` | "집으로 돌아가는 길", 목적지 없을 때 | | 1차 |

### 차 상태 (Vehicle, AAOS)
| 재료 | API | 이야기에서 | 콘솔 | 단계 |
|---|---|---|---|---|
| 기어 P, D | `Gear.registerGearSelection` | 출발, 도착 | 있음 | 1차 |
| 와이퍼 | `Wiper.registerWiperState` | 비 장면 | 있음 | 1차 |
| 전조등 | `Light.registerLowBeamLightState` | 밤, 터널 판단 (독서등 금지 조건) | 있음 | 1차 |
| 뒷좌석 착석 | `Seat.registerSeatOccupancy(ROW_2_*)` | 아이 탑승 | 있음 | 1차 |
| 뒷문 열림 | `Door` | 카시트 자리 탑승·하차 | 있음 | 1차 |
| 공조 켜짐, AUTO, 풍량 | `HVAC.getHvacPowerState`, `getHvacAutoState`, `getHvacFanSpeed` | 효과 가능 여부, 복귀 값 | 있음 | 1차 |
| 차속 | AAOS `CarPropertyManager` `PERF_VEHICLE_SPEED` | "바람처럼 달려요" | 있음 | 2차 |
| 핸들 각도 | `SteeringWheel` | 구불구불 뱀 길 | 있음 | 2차 |
| 방향지시등 | `TurnSignal` | "왼쪽 길로 가요!" | 있음 | 2차 |
| 주행 거리 | `Odometer` | "벌써 50km를 왔어요" | 있음 | 2차 |

| 날짜, 계절, 생일 | 기기 시각 + 등록 정보 | 크리스마스, 생일 장면 | 1차(시간대), 2차 |

### 사람 (기기 안에만 저장)
| 재료 | 외부 전송 | 단계 |
|---|---|---|
| 아이 이름 | 안 함 (`{주인공}` 치환) | 1차 (프리셋) |
| 나이 | 연령대만 | 1차 (프리셋) |
| 앉는 자리, 카시트 여부 | 안 함 | 1차 (프리셋) |

## 2. 몰입 효과 (출력)

| 감각 | 효과 | API | 좌석 | 콘솔 | 주행 중 규칙 | 단계 |
|---|---|---|---|---|---|---|
| 소리 | 낭독, 등장인물별 화자 | `TextToSpeech.speak`, `setSpeakerType` | 전체 | | 내비 안내 시 줄임 | 1차 |
| 소리 | 효과음, 배경음 | 앱 내 오디오 재생 | 전체 | | 같음 | 1차 |
| 빛 | 아이 자리 독서등 켜기·끄기 | `Light.setReadingLightSwitch` (밝기 없음) | 좌석별 | 뒤 좌·우 있음 | **주행 중 차량이 거부** → 정차 중에만, 전조등 켜짐이면 금지, 30초 | 1차 |
| 바람 | 풍량 +1단 | `HVAC.setHvacFanSpeed` | 구역(에뮬레이터는 하나) | 0~8단 | 공조 켜짐일 때만, 60초, 원래 값 복귀 | 1차 |
| 공기 | 내기·외기 전환 | HVAC 내외기 | 전체 | 있음 | "숲 공기를 마셔 봐" | 2차 |
| 몸 | 시트 열선·통풍 | `Seat.setHvacSeatTemperature`, `setHvacSeatVentilation` | 좌석별 | 앞좌석만 | 카시트 체감 약함 | 확장 |
| 소리 | 뒷좌석 전용 소리 | `TextToSpeech.setAudioZoneId` | 존 | 존 0번 하나뿐 | | 확장 |
| 창문 | 뒷좌석 블라인드 | `Window` 블라인드 | 좌석별 | 없음 | 동굴·밤 장면 | 확장 |

### 쓰지 않는 것
| 항목 | 이유 |
|---|---|
| 화면 (그림, 영상), 앰비언트, 실내등 | 화면 미사용 결정, 주행 중 운전자 시야 |
| 창문 열기 | 주행 중 아이 안전 |
| 풍향, 설정 온도, 에어컨 | 에뮬레이터는 앞좌석만 있어 운전자에게 영향 |
| 시트 위치 이동 | 안전 |
| 와이퍼, 도어 잠금, 트렁크 제어 | 운전 장치 |
| 과속 카메라, 경고등, 브레이크 | 운전 판단과 혼동 |

## 3. 주의

- 한국 주행 규제에서 "차량 설정"(`UX_RESTRICTIONS_NO_SETUP`)은 주행 중 금지. 앱의 독서등·풍량 제어가 여기에 걸리는지 **[확인 필요]**
  - 확인: `adb shell cmd hmg_car_service --service drivingstate driving_regulation on`
- 위 API 이름 중 독서등, 풍량, 착석, 기어, 와이퍼, 전조등, 내비, TTS는 SDK 파일에서 직접 확인함. 나머지는 문서 기준
